# Tarefas locais

Usar `.scratch/<feature>/spec.md` para especificações e `.scratch/<feature>/issues/NN-titulo.md` quando a decomposição em tarefas for necessária. Não criar issues remotas apenas pela existência de remote GitHub.

Estados convencionados pelo usuário: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. Registrar o estado em uma linha Status. Publicação remota depende de pedido explícito.
