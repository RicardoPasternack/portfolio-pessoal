# Portfólio — Ricardo Pasternack

Site de apresentação profissional e exposição de projetos.

## Tecnologias
- HTML
- CSS
- JavaScript

## Conceitos aplicados
- Estrutura semântica com header, nav, main, section e article.
- Organização do layout com Flexbox.
- Adaptação do conteúdo à largura da tela.
- Estilos organizados com classes e aninhamento de CSS.
- Estados de interação com hover e focus-visible.
- Navegação entre seções usando links internos.
- Seleção de elementos da página com querySelector.
- Funções e eventos de clique com addEventListener.
- Condições com if/else e valores booleanos.
- Exibição e ocultação de conteúdo com hidden.
- Atualização de aria-expanded para informar o estado do botão.

## Como visualizar
Abra o arquivo index.html em um navegador.

## Verificação
Layout conferido manualmente em janela larga e estreita.
Botão de detalhes testado com mouse e teclado.
